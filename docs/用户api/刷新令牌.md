需要用户授权令牌。[点击此处查看](../请求头部及签名方式.md)

# 请求
## 整体
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| refreshToken   | String(32)   | 是    | xxxxx                          | 刷新令牌                           |

---

# 响应
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| tokenType      | String(16)   | bearer                           | 令牌类型。目前固定为"bearer"         |
| scopes         | String(256)  | all                              | 授权范围。目前固定为"all"            |
| accessToken    | String(32)   | xxxxx                            | 访问令牌                           |
| accessTokenExpireTime | Long  | 1775786421624                    | 访问令牌的有效时间戳。毫秒级           |
| refreshToken   | String(32)   | xxxxx                            | 刷新令牌                           |
| refreshTokenExpireTime | Long | 1775786421624                    | 访问令牌的有效时间戳。毫秒级           |
