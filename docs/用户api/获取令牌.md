# 请求
## 整体
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| grantType      | String(32)   | 是   | password                        | 授权类型。目前固定为"password"       |
| phone          | String(20)   | 是   | 13800138000                     | 登录手机号码                        |
| password       | String(32)   | 是   | 123456                          | 明文密码                           |
| scope          | String(16)   | 否   | all                             | 授权范围。目前固定为"all"            |
| state          | String(128)  | 否   | xxxxxx                          | 状态参数，授权服务器会原样返回该参数    |

---

# 响应
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| tokenType      | String(16)   | bearer                           | 令牌类型。目前固定为"bearer"         |
| accessToken    | String(32)   | xxxxx                            | 访问令牌                           |
| accessTokenExpiresIn | Integer | 1624018181                      | 访问令牌的有效期，单位为秒            |
| refreshToken   | String(32)   | xxxxx                            | 刷新令牌                           |
| refreshTokenExpiresIn | Integer | 1624018181                     | 刷新令牌的有效期，单位为秒            |
| state          | String(128)  | xxxxx                            | 状态参数，原样返回入参中的state参数    |
