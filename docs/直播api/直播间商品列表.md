# 请求
## 整体
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| roomId         | Long         | 是   |   123456                        | 直播间id                           |
| pointer        | Pointer      | 是   |                                 | 分页                               |


## Pointer
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| limit          | Integer      |  是  | 10                              | 分页查询的记录数，默认为10，最大100    |
| offset         | Integer      |  是  | 0                               | 记录数开始指针                     |

# 响应
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| goodsList      | List<Goods>  |                                  | 商品列表                           |

## Goods
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| goodsId        | Long         | 123456                           | 商品id                             |
| roomId         | Long         | 123456                           | 直播间id                           |
| storeId        | Long         | 123456                           | 店铺id                             |
| description    | String(64)   | 扣扣连衣裙                         | 商品标题                           |
| defaultImage   | String(256)  | https://img1.ppwang.com/xxx.jpg  | 商品封面图url                       |
| ifShow         | Integer      | 1                                | 是否上架。0-下架，1-上架              |
| videoUrl       | String(256)  | https://xxx.com/xx.mp4           | 商品视频url                         |
| explainVideoUrl| String(256)  | https://xxx.com/xx.mp4           | 商品讲解视频url                      |
| retailPrice    | Long         | 9944                             | 拿货价。单位为分                      |
| packPrice      | Long         | 9044                             | 打包价。单位为分                      |

| goodsExplainVideoPlay | GoodsExplainVideo |                      | 商品讲解视频播放地址                  |

## Spec
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| specId         | Long         | 123                              | 规格id                             |
| spec           | String(64)   | 黄色 均码                         | 规格名称                           |
| stock          | Integer      | 100                              | 库存                              |
| color          | String(16)   | 黄色                              | 颜色                              |
| size           | String(16)   | 均码                              | 尺码                              |

## GoodsExplainVideo
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |

| mp4Url         | String(256)  | https://xxx.com/xx.mp4           | mp4播放地址                        |
| baseM3u8Url    | String(256)  | https://xxx.com/xx.m3u8          | 原始m3u8地址，该地址会过期            |
