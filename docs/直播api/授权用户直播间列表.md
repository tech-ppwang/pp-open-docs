# 请求
## 整体
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| status         | Integer      | 否   | 1                               | 直播间状态。0未直播，1直播中，2直播结束  |
| pointer        | Pointer      | 是   |                                 | 分页                               |


## Pointer
| 字段            | 类型         |是否必须| 示例                            | 描述                              | 
| -------------- | ------------ | ---- | ------------------------------- | --------------------------------- |
| limit          | Integer      |  是  | 10                              | 分页查询的记录数，默认为10，最大100    |
| offset         | Integer      |  是  | 0                               | 记录数开始指针                     |

---

# 响应
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| roomList       | List<Room>   |                                  | 直播间列表                          |

## Room
| 字段            | 类型         | 示例                              | 描述                               | 
| -------------- | ------------ | -------------------------------- | --------------------------------- |
| storeId        | Long         | 123456                           | 店铺id                             |
| storeName      | String(32)   | 某某店                            | 店铺名称                            |
| roomId         | Long         | 123456                           | 直播间id                           |
| roomName       | String(32)   | xxx开播啦                         | 直播间名称                          |
| roomCover      | String(256)  | https://img1.ppwang.com/xxx.jpg  | 直播间封面url                       |
| pushUrl        | String(256)  | https://xxxx.com/xxx             | 直播间推流地址                       |
| status         | Integer      | 直播间状态                         | 0未直播，1直播中，2直播结束            |
| startTime      | Integer      | 1624018181                       | 直播开始时间，单位为秒级时间戳          |
| endTime        | Integer      | 1624018181                       | 直播结束时间，单位为秒级时间戳          |
